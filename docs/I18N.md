# Internationalisation (SPEC §10.1, §10.8)

Four languages: English (`en`, the source), German (`de`), Polish (`pl`), Russian (`ru`). Code: `src/i18n/`.

## Using it

```ts
import { t, tp, formatNumber, formatDistance, formatTimeLimit, formatDate, worldName, errorMessage,
         setLanguage, onLanguageChange, getLanguage } from '../i18n';

t('round.counter', { round: 2, total: 5 });          // "Round 2/5"
t('start.best', { score: formatNumber(18450) });     // "Best score: 18,450" / "Bestleistung: 18.450"
tp('room.playerCount', 5);                           // "5 players" / "5 игроков" / "5 graczy"
t('room.playerCount', { count: 5 });                 // same thing
formatDistance(12.34);                               // "12.3 m" / "12,3 m" / "12,3 м"
formatTimeLimit(120);                                // "2 min" / "2 мин"; 0 → "No limit"
formatDate('2026-10-07');                            // "October 7, 2026" / "7 октября 2026 г." (UTC date)
worldName('valley', infoName);                       // "Долина Рудников"; unknown slug → infoName
errorMessage(apiError.error);                        // localized ApiErrorCode, generic text for unknown codes
```

- **Keys** are flat strings `area.name` (`menu.play`, `error.room_full`, `world.valley.desc`). `en.ts` is an
  `as const` object and the source of `MessageKey`; `de.ts`/`pl.ts`/`ru.ts` are typed `Dictionary`, so a missing,
  extra or wrongly shaped entry does not compile. `src/i18n/types.ts` also checks at compile time that every
  `ApiErrorCode` from `shared/api.ts` has an `error.<code>` key.
- **Placeholders** are `{name}`. Numbers are inserted with `String()`: format them first (`formatNumber`) when they
  are quantities; ids such as `{seed}` stay ungrouped. An unknown placeholder stays visible as `{name}`.
- **Plurals**: the entry is an object of `Intl.PluralRules` categories, `other` mandatory:
  `'room.playerCount': { one: '{count} игрок', few: '{count} игрока', many: '{count} игроков', other: '{count} игрока' }`.
  `t` picks the form by `params.count` (a number), `tp(key, count)` is the shorthand. `{count}` is formatted with
  the locale unless passed as a string. English/German use `one`/`other`; Polish and Russian need `one`, `few`,
  `many` and `other` (`other` is the fractional form). The test asserts every integer category is present.
- **Language state**: `initLanguage()` (called once at boot in `main.ts`) applies `detectLanguage()`: the stored
  choice `localStorage['gothic2guessr.lang']` wins, else the first `navigator.languages` entry whose primary subtag is
  supported (`de-AT` → `de`), else `en`. Storage access is guarded (private mode, blocked storage).
  `setLanguage(lang)` stores the choice, sets `<html lang>` (which switches the fallback font, see
  [FONTS.md](FONTS.md)) and calls the `onLanguageChange` subscribers. Until `initLanguage`/`setLanguage` runs the
  language is English, so unit tests see English text.
- **Re-render**: `Screens` subscribes itself and rebuilds the start screen (keeping the unsaved world/mode/toggle/seed
  choices and the selector's focus) and the summary. Round and result screens keep their text until the next screen;
  the selector is not reachable from them. New screens should subscribe the same way and unsubscribe on teardown.
- **Language selector**: `createLangSelect({ corner?, className?, onChange? })` in `src/ui/langselect.ts` returns
  `{ root, update, destroy }`: a radio group showing each language by its own name with a `lang` attribute (so
  "Русский" renders in the Cyrillic-capable font inside an English page). Call `destroy()` when discarding it.

## Adding a key

1. Add it to `en.ts` (string or plural object) in the right section.
2. `npx tsc --noEmit` lists the three dictionaries that now miss it; translate it there with the same placeholders.
3. `npx vitest run tests/i18n.test.ts` checks key sets, placeholders, plural categories and blank strings.

The stage-3 screens already have keys: main menu (`menu.*`), time limits (`time.*`, `start.timeLimit`), countdown and
timeouts (`round.timeLeft`, `round.timedOut`, `result.timedOut`), daily (`daily.*`), sharing (`share.*`,
`summary.challengeLink`…), leaderboard (`lb.*`), challenge page (`challenge.*`), settings summaries (`settings.*`),
rooms (`room.*`), duel (`duel.*`), every server error (`error.*`) plus `error.network` and `error.unknown`.

## Terminology

World names follow the official releases (checked against the Polish and Russian walkthrough/wiki pages, e.g.
gry-online.pl's *Noc Kruka* guide and Russian articles on *Ночь Ворона*; the fandom wikis were not reachable from
here, HTTP 402):

| slug | en | de | pl | ru |
|---|---|---|---|---|
| `khorinis` | Khorinis | Khorinis | Khorinis | Хоринис |
| `valley` | Valley of Mines | Minental | Górnicza Dolina | Долина Рудников |
| `jharkendar` | Jharkendar | Jharkendar | Jarkendar | Яркендар |

Add-on title: *Die Nacht des Raben* / *Noc Kruka* / *Ночь Ворона* (used in the logo's alt text and in the Jharkendar
description).

Other choices, kept consistent across all screens:

| Concept | en | de | pl | ru | Note |
|---|---|---|---|---|---|
| Guess (button) | Guess | Raten | Zgadnij | Угадать | "Tipp" / "typ" / "ответ" for the placed marker |
| Party room | Party | Gruppe | Drużyna | Отряд | "отряд" fits the Gothic setting better than "вечеринка" |
| Room host | Host | Anführer | Przywódca | Вожак | |
| Duel health | HP / Health | LE / Lebensenergie | PŻ / Punkty życia | ОЗ / Здоровье | German "Lebensenergie" is the game's own term; the Polish and Russian status-screen terms were not verified, the common RPG terms are used |
| Daily challenge | Daily challenge | Tägliche Herausforderung | Wyzwanie dnia | Испытание дня | |
| Challenge (link) | Challenge | Herausforderung | Wyzwanie | Вызов | |
| No move / No look | No move / No look | Ohne Laufen / Ohne Umsehen | Bez ruchu / Bez rozglądania | Без ходьбы / Без обзора | |
| Seed | Seed | Seed | Ziarno | Сид | only on the stage-2 start screen |

Russian addresses the player with "вы" (lowercase), German with "du", Polish with "ty", as the games' own menus and
most game UIs do. Language names in the selector are endonyms and identical in every dictionary.

## Not localized (on purpose)

- Technical error details from the loaders (`HTTP 404 for /data/…`) inside the localized frame
  (`start.worldUnavailable`, `boot.indexFailed`): they are for bug reports.
- The admin UI (English only, SPEC §10.1).
- `GAME_MODES[].label/description` in `src/game/state.ts` stay English for tests and logs; the UI uses `mode.*`.
