# Backlog (отложенные идеи)

Записано 2026-10-07 после обсуждения третьего этапа. Ничего из этого не входит в stage 3.

1. **Режим регионов (Region Streak).** Игрок угадывает не точку, а регион (Город Хоринис, Ферма Онара, Монастырь,
   Старый лагерь, Лагерь пиратов…), серия до первой ошибки. Регионы берутся из префиксов вейпоинтов
   (`NW_CITY_*`, `NW_FARM1_*`, `NW_MONASTERY_*`, `OC_*`, `ADW_PIRATECAMP_*`).
2. **Королевская битва по регионам.** Каждый раунд выбывают не угадавшие регион или самые далёкие от точки.
3. **Профиль игрока.** Средние очки по мирам, тепловая карта промахов, ачивки.
4. **Подборки локаций** («Только город», «Шахты Долины», «Пещеры и подземелья»): фильтры по префиксам и флагу
   `outdoor`. Нужна ручная модерация подборок.
5. **Командный и кооперативный режимы**: команда против команды, общая отметка группы, формат для стримов.
6. Подбор случайного соперника (matchmaking) и рейтинг Elo по дуэлям: имеет смысл, когда появится живая аудитория.

Отклонено: тематические ранги и внутриигровая валюта.
