# docs/recon

Renders from the research phase (`RECON.md`): top-down maps of the three worlds, sample panoramas, the in-game map,
early UI screenshots and the exported Khorinis waypoint network (`waynet_newworld.json`, `bounds_*.json`). They are
made from the game files (THQ Nordic / Piranha Bytes) and are not in the repository. `tools/render.py` and
`tools/probe_world.py` recreate them from your own copy of the game (`GOTHIC2_DIR`, see the main README).
