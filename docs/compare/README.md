# docs/compare

Side-by-side crops of the original panoramas and the re-encoded release variants (face size / WebP quality), made
while picking the deployment setting (`tools/make_compare.py`, `dev/compare.html`, `tools/make_release.py`). They
show the game's world, so they are not in the repository; build the dataset from your own copy of the game and run
`tools/make_compare.py` to compare variants.
